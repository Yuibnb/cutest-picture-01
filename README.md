# cutest-picture-01 — V4: baby otter in a bubble bath

A baby otter with huge bright blue eyes smiles from a wooden tub of foam
bubbles, a tiny sleeping yellow chick nestled on its head. Entry for the
make.fun cutest-picture-01 bounty (eager-finch-50).

- `entry.png` — the picture (JPEG, 1024x1024, under 1 MiB).
- `main.py` — copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
  (deterministic: two runs produce byte-identical output).
- `LICENSE` — MIT.
- `.makefun/owner.json` — payout wallet.
